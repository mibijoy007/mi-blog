## Replace method



The `replace(" ", "-")` method only replaces the first occurrence of space,
```js
const result = 'example first sting'.replace(' ', '-');
console.log(result);  // Output: "example-first sting" 
```
Here, we can see that the string `example first sting` is not done .

#### But, we can use **RegExp** : 

```js
const result = 'example first sting'.replace(/ /g, '-');
console.log(result);  // Output: "example-first-sting"
```

Here, The space character (' ') which was denoted by `RegExp` which is (/ /)  being targeted for spaces, and the `g` flag ensures all spaces are replaced globally
